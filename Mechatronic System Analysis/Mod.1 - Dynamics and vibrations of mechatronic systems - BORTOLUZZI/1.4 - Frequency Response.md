# Frequency Responde
![[Black_box_freq_analysis.webp]]
Given a system with input $U(S)\to u(t)$ and output $Y(s)\to y(t)$ and the transferring function $G(s)\to g(s)$, where:
- $u(t)=M \sin(\omega t) \to U(s)=M \frac{\omega}{s^2+\omega^2}$
- $Y(s)=\underbrace{G(s)U(s)}_{X_{homog}(s)}+\underbrace{\frac{A(s)}{B(s)}}_{X_{part}(s)}$
$$
\begin{matrix}
Y(s) = \frac{A(s)}{B(s)} + G(s)M\frac{\omega}{s^2 + \omega^2} =\\
\frac{A(s)}{(s-p_1)(s-p_2)} + \frac{N(s)}{(s-p_1)(s-p_2)} M \omega \frac{1}{(s-j\omega)(s+j\omega)}
\end{matrix}
$$

where $G(s) = \frac{N(s)}{D(s)}$ for a second-order system, this expands via partial fraction decomposition into:
$$
\begin{matrix}
= \underbrace{\left(\frac{R_{1h}}{s-p_1} + \frac{R_{2h}}{s-p_2}\right)}_{\text{damped oscillation}} + \underbrace{\left(\frac{R_{1p}}{s-p_1} + \frac{R_{2p}}{s-p_2}\right)}_{\text{damped osc.}} + \underbrace{\left(\frac{R_{3p}}{s-j\omega} + \frac{R_{4p}}{s+j\omega}\right)}_{\text{no dampening}}
\end{matrix}
$$

---

### Time Domain Response ($y(t)$)

$$y(t) = \underbrace{R_{1h} e^{p_1 t} + R_{2h} e^{p_2 t}}_{\text{damped oscillation}} + \underbrace{R_{1p} e^{p_1 t} + R_{2p} e^{p_2 t}}_{\text{damped osc.}} + \underbrace{R_{3p} e^{j\omega t} + R_{4p} e^{-j\omega t}}_{\text{no dampening}}$$
![[Different_oscillation_for_oscillation_input.webp]]
---

### Steady-State Behavior ($t \gg \tau$)

If $t \gg \tau$:

$$y(t) \cong R_{3p} e^{j\omega t} + R_{4p} e^{-j\omega t} = 2 \left|R_{3p}\right| e^{0 t} \cos\left[\omega t + \text{Arg}(R_{3p})\right]$$
*(where $|R_{3p}| = |R_{4p}|$ and $e^{0t}=1$ for steady-state sinusoidal oscillation {No dampening})*

Therefore, we need to know $R_{3p}$ and $R_{4p}$ to know the permanent oscillation configuration after the transient period $\tau$.

> **Note on stability:** 
> $p_1, p_2$ are **stable** $\iff$ negative real part ($\text{Re}(p_{1,2}) < 0$).

## Derivation of Steady-State Amplitude ($R_{3p}, R_{4p}$)

To get $R_{3p}$ we start from:
$$R_{3p} = \left[ (s - j\omega) G(s) M \frac{\omega}{(s - j\omega)(s + j\omega)} \right]_{s = j\omega} = \frac{G(j\omega) M \cancel \omega}{2j\cancel \omega}$$

$$R_{4p} = \left[ (s + j\omega) G(s) M \frac{\omega}{(s - j\omega)(s + j\omega)} \right]_{s = -j\omega} = -\frac{G(-j\omega) M \cancel \omega}{2j \cancel \omega}$$

We need:
$$\left|R_{3p}\right| = \left|G(j\omega)\right| \frac{M}{2} = \left|R_{4p}\right|$$
$$\text{Arg}(R_{3p}) = \text{Arg}[G(j\omega)] - \frac{\pi}{2} = \varphi - \frac{\pi}{2}$$
*(where $\text{Arg}(G(j\omega)) = \varphi(j\omega)$)*

$$\text{Arg}(R_{4p}) = \text{Arg}\left[-G(-j\omega) - \frac{\pi}{2}\right] = \pi - \varphi - \frac{\pi}{2} = -\varphi + \frac{\pi}{2}$$
> *(noting that $G(s^*) = G^*(s)$)*
> ![[G(s*)=G*(s).webp|292]]

---

### Time Response Equation

$$y(t) = 2 \frac{M}{2} \left|G(j\omega)\right| \cos\left(\omega t + \varphi(j\omega) - \frac{\pi}{2}\right)$$

$$y(t) = M \left|G(j\omega)\right| \sin\left(\omega t + \varphi(j\omega)\right)$$
The output is the input function but with amplitude scaled and with a different phase.
* **Amplitude:** $M \cdot |G(j\omega)|$
* **Phase:** $\sin\left(\omega t + \underbrace{\varphi(j\omega)}_{{\text{phasing factor}}}\right)$ (different phase)

---

### Graphical & Parameter Interpretation
![[graph of the response of sin input.webp]]

* **Initial conditions:** Not $x_0$ and $\dot{x}_0$ because we have neglected the homogeneous part and the part of the particular solution that doesn't depend on the input.
* **System mapping:** 
  $$G(s) \xrightarrow{s = j\omega} G(j\omega) \implies \begin{cases} |G(j\omega)| \\ \text{Arg}(G(j\omega)) = \varphi(j\omega) \end{cases}$$
* **Frequency response function for standard second-order system:**
  $$G(s) = \frac{1/m}{s^2 + 2\xi\omega_n s + \omega_n^2} \xrightarrow{s = j\omega} G(j\omega) = \frac{1/k}{1 - \left(\frac{\omega}{\omega_n}\right)^2 + j2\xi\left(\frac{\omega}{\omega_n}\right)}$$
  This new notion show as $\omega_n$ scales the system sensitivity to the input frequency.
---

### Magnitude and Phase Expressions

$$\left|G(j\omega)\right| = \frac{\frac{1}{k}}{\sqrt{\left[1 - \left(\frac{\omega}{\omega_n}\right)^2\right]^2 + \left[2\xi\left(\frac{\omega}{\omega_n}\right)\right]^2}}$$

$$\text{Arg}(G(j\omega)) = 0 - \arctan\left(\frac{2\xi\left(\frac{\omega}{\omega_n}\right)}{1 - \left(\frac{\omega}{\omega_n}\right)^2}\right)$$

---

### Bode Plot Insights & Quality Factor ($Q$)
![[1.4 - Frequency Response.webp|578]]
To start understanding how the parameter seen previously impact the frequency response, we start assuming that $\xi = 0$, therefore:
$$
\exists \ \omega_{\max} = \omega_n \sqrt{1 + 2\xi^2} < \omega_d = \omega_n \sqrt{1-\xi^2}
$$
  * $\left|G(j\omega)\right|$ peak depends on $\xi$.
  * If $\xi = \frac{\sqrt{2}}{2}$, $\omega_{\max} = 0 \implies |G(j\omega)|$ decreases monotonically.
* **Quality Factor ($Q$):**
  $$Q = k |G(j\omega_{\max})| = \frac{1}{2\xi\sqrt{1-2 \xi^2}}$$
  * $Q \approx \frac{1}{2\xi}$ if $\xi$ is small.
  * For $\xi \to 0$, quality factor approaches $\infty$ (undamped resonance).
